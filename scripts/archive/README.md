# Archived Scripts

This directory is for historical experiment scripts that are kept for
provenance rather than day-to-day use.

- `campaigns/`: one-off campaign generators, dynamic sweep launchers, reset
  helpers, re-evaluation helpers, and report renderers for completed campaigns.
- `ksivi_parity/`: scripts from the KSIVI BNN parity investigation.

For new work, prefer the top-level scripts documented in
`scripts/README.md`, especially `run_default_config_grid_sweep.py` and
`run_finalization.py`.
