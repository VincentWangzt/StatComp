\section{Experiments}
\label{sec:experiments}

We evaluate DSIVI across posterior inference problems that increase in dimension and structure.  We begin with two-dimensional synthetic targets, where the geometry of the approximation can be inspected directly.  We then move to a 100-dimensional conditioned diffusion posterior, where a useful approximation must recover both the mean path and posterior uncertainty.  Finally, we consider Bayesian neural-network (BNN) regression posteriors with several hundred latent variables, where performance is measured through posterior predictive accuracy.  Unless stated otherwise, tables report the mean and standard error over five random seeds.

Our main comparisons are against UIVI and AISIVI \citep{uivi2019,pielok2025revisiting}.  We also include SIVI \citep{yin2018semi} and KSIVI \citep{cheng2024kernel} where their objectives and implementations apply.  Additional target definitions, metrics, and training details are collected in Appendix~\ref{app:experiment-details}.

\subsection{Toy two-dimensional targets}
\label{subsec:toy-experiments}

We first use low-dimensional targets to check whether the learned semi-implicit distribution captures visible features of the target density before turning to higher-dimensional settings.  The main text focuses on the three plotted targets in \cref{fig:toy-scatter-grid}: \texttt{x\_shaped}, \texttt{student\_uc}, and \texttt{8\_gaussians}.  These targets respectively probe intersecting ridges, heavy-tailed dependence, and multi-modal coverage.  Full target details and quantitative diagnostics are given in Appendix~\ref{app:toy-details}.

\Cref{fig:toy-scatter-grid} shows that DSIVI preserves the main geometry across the plotted targets.  On \texttt{x\_shaped}, it follows the four arms of the density; on \texttt{student\_uc}, it maintains the diagonal ridge and tail direction; and on \texttt{8\_gaussians}, it places mass on the individual modes with less between-mode spreading than AISIVI and UIVI in this evaluation.  We use these examples as qualitative evidence that the denoising reverse model does not disrupt the basic semi-implicit sampler before testing the method in higher dimensions.

\subsection{Conditioned diffusion process}
\label{subsec:langevin-experiments}

We next evaluate a 100-dimensional conditioned diffusion posterior used in recent SIVI evaluations \citep{cheng2024kernel,pielok2025revisiting}.  The latent path follows the double-well Langevin SDE
\begin{equation}
  dx_t = 10x_t(1 - x_t^2)\,dt + dw_t,
  \qquad 0 \leq t \leq 1,
  \qquad x_0 = 0,
\end{equation}
where $w_t$ is one-dimensional Brownian motion.  We discretize the path with Euler-Maruyama step size $\Delta t=0.01$, giving
\begin{equation}
  x = (x_{\Delta t}, x_{2\Delta t}, \ldots, x_{100\Delta t}) \in \mathbb{R}^{100}.
\end{equation}
Observations are made every five time steps,
\begin{equation}
  y = (y_{5\Delta t}, y_{10\Delta t}, \ldots, y_{100\Delta t}),
  \qquad
  y_{5k\Delta t} \mid x_{5k\Delta t}
  \sim \mathcal{N}(x_{5k\Delta t}, \sigma^2),
\end{equation}
for $k=1,\ldots,20$ and $\sigma=0.1$.  The inference target is therefore $p(x \mid y) \propto p_{\mathrm{prior}}(x)p(y \mid x)$, with likelihood
\begin{equation}
  p(y \mid x)
  =
  \prod_{k=1}^{20}
  \frac{1}{\sqrt{2\pi\sigma^2}}
  \exp\left\{-\frac{(y_{5k\Delta t}-x_{5k\Delta t})^2}{2\sigma^2}\right\}.
\end{equation}
This benchmark is useful because posterior quality is visible not only through the mean path, but also through the marginal uncertainty band.

  \label{fig:langevin-trace-grid}
\end{figure}

\Cref{fig:langevin-trace-grid} shows that DSIVI tracks the latent trajectory while maintaining a posterior band comparable to the strongest baselines.  \Cref{tab:langevin-final-eval} reports KDE ELM, a kernel-density estimate of the expected log marginal score against reference samples; larger values indicate better agreement with the reference posterior.  DSIVI reaches essentially the same KDE ELM as UIVI and KSIVI while using the same 10,000 main VI iterations as UIVI and AISIVI.  Further metric and training details are in Appendix~\ref{app:diffusion-details}.

\subsection{Bayesian neural-network regression}
\label{subsec:bnn-experiments}

We finally evaluate posterior inference for Bayesian neural networks on six UCI regression targets: Boston Housing, Concrete, Power Plant, Protein, Wine Red, and Yacht.  Following the BNN settings used for KSIVI and SIVI-SM \citep{cheng2024kernel,yu2023semi}, each target uses a single-hidden-layer ReLU network with 50 hidden units.  The latent variable is the flattened vector of weights, biases, and precision parameters, giving dimensions 751, 501, 301, 551, 651, and 401 respectively.  Because these posteriors are high-dimensional and data-dependent, we evaluate posterior predictive performance through test RMSE and negative test log-likelihood (NLL), both lower being better.  Dataset and evaluation details are in Appendix~\ref{app:bnn-details}.

\paragraph{Training.}

\subsection{Conditioned diffusion process}
\label{app:diffusion-details}

\paragraph{Setup.}
The diffusion posterior is the 100-dimensional discretized path posterior described in Section~\ref{subsec:langevin-experiments}.  Reference samples are produced by the long-run sampler used for the comparison figures and metrics.  The trace plots show posterior mean paths and marginal 95\% posterior intervals against the true latent path and the noisy observations.

\paragraph{Metrics.}
KDE ELM evaluates coordinate-wise kernel-density estimates from model samples at reference samples.  The reported evaluation uses 1,000 reference samples and 100,000 model samples, with chunked evaluation to keep memory use bounded.  Sliced Wasserstein diagnostics are computed with the same sample and projection counts as in the two-dimensional experiments.

\paragraph{Training.}
SIVI, UIVI, AISIVI, and DSIVI are reported after 10,000 main VI iterations.  KSIVI is reported after 50,000 iterations, matching the selected comparison setting for this benchmark.  DSIVI uses the standard semi-implicit variational sampler together with a denoising reverse model.

\subsection{Bayesian neural-network regression}
\label{app:bnn-details}

\paragraph{Setup.}
Each BNN target uses a one-hidden-layer ReLU network with 50 hidden units.  The input dimensions are 13 for Boston, 8 for Concrete, 4 for Power, 9 for Protein, 11 for Wine Red, and 6 for Yacht.  Including weights, biases, and two precision variables, the corresponding posterior dimensions are 751, 501, 301, 551, 651, and 401.  The datasets contain 506, 1,030, 9,568, 45,730, 1,599, and 308 observations respectively.  Data preparation uses a fixed random seed, a 90/10 train-test split, input standardization based on the training split, and target standardization for training labels.  Test labels are evaluated on their original scale.

\paragraph{Metrics.}
BNN evaluation draws 2,000 posterior samples from the learned variational distribution.  RMSE is computed from the posterior predictive mean on the test set.  Test log-likelihood is estimated by Monte Carlo marginalization over posterior samples, and the reported NLL is its negative.  These predictive metrics are the primary evaluation criteria for the BNN regression setting.

\paragraph{Training.}
The reported BNN evaluation uses five seeds for each method and target.  DSIVI uses VI pretraining on the development split, EMA for evaluation, 10,000 main training epochs, training batch size 128, reverse batch size 2,048, reverse learning rate $10^{-3}$, and two reverse-model updates per main epoch.  UIVI is the unbiased implicit variational inference baseline, AISIVI is the annealed importance-sampling refinement, and KSIVI optimizes a kernel Stein discrepancy objective with the strengthened BNN configuration used for this comparison.
