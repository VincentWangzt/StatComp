# Standard Gaussian benchmark

This folder contains the benchmark for the standard Gaussian target `standard_gaussian`, implemented as `N(0, I_2)`.

Methods:

- `DIVI`: executed with the internal runner name `DSIVI`.
- `UIVI`: executed with `UIVI`.
- `KDVI`: executed with `KDVI`.

Remote GPU workflow:

```bash
cd /root/StatComp
git pull
conda activate stat_comp
bash test_standard_gaussian/run_remote.sh
```

Outputs generated by `test_standard_gaussian/plot_curves.py`:

- `test_standard_gaussian/kl_curve.png`
- `test_standard_gaussian/w2_curve.png`
- `test_standard_gaussian/metric_curves.csv`
- `test_standard_gaussian/final_metrics.csv`
- `test_standard_gaussian/runs/{DIVI,UIVI,KDVI}/`
