# Flat Gaussian benchmark

This folder contains the runnable benchmark requested for the flat Gaussian
target `flat_gaussian`, implemented in the project as `N(0, diag(1, 10^2))`.
The covariance is positive definite so KL and W2 evaluation can use exact
target samples.

Methods:

- `DIVI`: executed with the internal runner name `DSIVI`.
- `UIVI`: executed with `UIVI`.
- `KDVI`: executed with `KDVI`.

Remote GPU workflow:

```bash
cd /root/StatComp
git pull
conda activate stat_comp
bash test_gaussian/run_remote.sh
```

Outputs generated by `test_gaussian/plot_curves.py`:

- `test_gaussian/kl_curve.png`
- `test_gaussian/w2_curve.png`
- `test_gaussian/metric_curves.csv`
- `test_gaussian/final_metrics.csv`
- `test_gaussian/runs/{DIVI,UIVI,KDVI}/`
